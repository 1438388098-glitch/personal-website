## 问题与边界

一道错题值得看的，是它反复指向的知识点。这个技能把竹马法考错题本里的全部错题，变成按科目分册、可直接背诵的知识点笔记 PDF：从错题反推高频考点、补易错易混点，并按你的薄弱科目、复习进度和学习习惯调整详略。边界：个人学习用途的非官方工具，与平台无任何关联；对平台只读（不交卷、不动作答记录），仅抓本人账号的错题；仅覆盖客观题，主观题错题本结构不同，未适配。

## 机制

七阶段流程由 Agent 按 SKILL.md 自主编排：扫码登录后走内部只读接口全量抓取（题干、选项、正确答案、完整官方解析，串行加默认 150ms 间隔），按科目切成不超过 55 题的单元交给并行 subagent 生成笔记，随后按「科目 × 维度」做六维并行审查（法条准确性、答案一致性、覆盖完整性、格式合规、学员适配、跨单元衔接），汇总成修订清单，P0 问题必须修订并复审，之后才渲染 PDF。防御性工程贯穿始终：JSON 落盘原子写、进程锁防并发、断点续跑、熔断退避；subagent 提示词内置防注入条款与写入路径白名单；汇总脚本解析不出问题条目时直接报错，绝不产出「无需修订」的假绿灯。

## 验证

一次完整运行的实测规模如实记录：1655 道唯一错题（18 科目、180 个有题章节）、41 个处理单元，抓取约 9 分钟；39 个笔记生成 subagent 五批并行（另 2 个单元因 429 限流由主 Agent 手写）；产出 18 份单科 PDF 共 8.3MB 加 129 页总册 4.2MB。npm test 共 22 例，覆盖参数解析、原子写、进程锁过期抢占、切分单元与 manifest、假绿灯防护（有报告但零解析必须 exit 2），全部基于临时目录的 CLI 端到端验证。仓库另经两轮独立代码审查加复审验收（安全审计、逐行审查、文档一致性核查），过程留痕于 git 历史与安全审计文档。

## 已知失败

接口拿不到「我的错选」：userOptions 与 userAnswer 恒为 null，只知道哪些题错了，不知道你当时勾了哪个选项。依赖竹马内部接口，前端改版可能失效；登录态会过期，需重新扫码。总册 PDF 中各单元章节编号彼此独立，会出现编号重起，已用「第 N 部分（续）」缓解。两条出本机的数据通道需要知情：错题内容与学情会作为提示词发送给所用的模型服务商；--desktop 会把总册 PDF 复制到桌面，若桌面在云同步范围内该文件会上云。
