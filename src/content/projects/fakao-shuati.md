## 问题与边界

主观题备考缺一个能反复练、练完立刻按采分点改的地方：市面平台题目固定，自己的错题没法沉淀。这个平台自托管，题库自己灌，答完一键提交 AI 按采分点判分。边界说在前面：仓库是纯工具，不含任何题目、答案、解析或采分点（著作权边界），题库数据需要用你自己在题库平台的合法账号获取；AI 判分结果只作练习参考，与真实阅卷有差异。部署上按私有服务设计：全站密码保护、noindex 响应头、worker API 随机 token，不建议无保护暴露公网。

## 机制

答题页两栏布局，题干左侧固定，每个小问独立作答框，5 秒自动保存，带考试日倒计时和模拟计时。判分按 fakao-grader 的采分点口径，AI 输出结构化分数加 Markdown 复盘：逐点对照、丢分类型分布（结论 / 依据 / 分析）、答案与作答对比。错题本从丢分采分点自动派生，重做通过即清除；背诵模块把采分点做成抽认卡，可标记掌握。统计面板给得分率、采分点命中趋势和科目覆盖进度。多账号数据隔离，适合和朋友合租一台服务器。
